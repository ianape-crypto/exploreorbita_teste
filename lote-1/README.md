# órbita.

**Inglês para explorar.** Mais de 50 jogos no navegador para praticar inglês do A1 ao C1, sem cadastro: é só abrir e jogar.

👉 **[Jogar agora](https://SEU-USUARIO.github.io/orbita/)**

![Tela inicial do Órbita](screenshot.jpg)

## O que é

O Órbita é uma coleção de jogos curtos para treinar vocabulário, gramática, escuta e pronúncia em inglês. Cada jogo se ajusta ao nível escolhido, e as instruções estão em português para que o foco fique no inglês.

## Destaques

- **54 jogos** em 5 categorias, mais uma seleção de indicados
- **Níveis do A1 ao C1**, ajustáveis a qualquer momento pelo botão *Nível*
- **Escape Room**: casos em lugares diferentes, com o texto em 4 níveis (A1–A2, B1, B2, C1)
- **Áudio** nos jogos de escuta e pronúncia, usando a voz do próprio navegador
- **Favoritos** marcados com estrela, para achar rápido os jogos preferidos
- **Botão "Try me!"**, que sorteia um jogo aleatório
- **Funciona no celular, no tablet e no computador**

## Como rodar no seu computador

O site é estático: HTML, CSS e JavaScript, sem instalação.

1. Baixe o repositório (**Code → Download ZIP**) e descompacte.
2. Abra o arquivo `index.html` no navegador.

> Os jogos de áudio dependem das vozes em inglês instaladas no seu sistema. Chrome e Edge costumam ter as melhores.

## Estrutura

```
index.html        a página e todos os jogos
covers/           capas dos jogos
img/              cenários e objetos do Escape Room
img/icons/        ícones dos jogos
favicon.png       ícone da aba
```

## Seus dados

Não existe conta nem servidor. Favoritos, nível escolhido e progresso ficam salvos apenas no navegador de quem joga (localStorage). Limpar os dados do navegador apaga esse histórico.
