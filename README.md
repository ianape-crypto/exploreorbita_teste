# exploreorbita_teste
Órbita: inglês para explorar. Mais de 50 jogos no navegador para praticar inglês do A1 ao C1: memória, forca, wordle, scrabble, caça-palavras, detetive de erros, ditado, escape rooms e muito mais. Organizados em vocabulário, gramática, escuta e pronúncia, com nível ajustável e favoritos. Sem cadastro: é só abrir e jogar.
